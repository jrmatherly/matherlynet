## Phase 1: Deploy blockers

### Task 1: Trust Cloudflare's forwarded protocol so form POSTs aren't rejected (C1)

**Files:**

- Modify: `web/astro.config.mjs` (the `security` block)
- Scratch: `$SCRATCH/origin-check.sh` (not committed)

**Interfaces:** none.

Research: `security.allowedDomains` is `{ hostname?, protocol?, port? }[]`
(`astro/dist/core/config/schemas/base.js:235-241`; <https://docs.astro.build/en/reference/configuration-reference/#securityalloweddomains>).
When non-empty, Astro applies validated `X-Forwarded-Proto/Host/Port` before the origin check
(`fetch-state.js:239-241, 804-840`; `origin-check.js:15`). The value is baked into the manifest at build time.

Side effects, from `astro/dist/core/app/node.js` (`createRequest`) and `validate-headers.js`:

- A `Host` that doesn't match an entry (e.g. `www.matherly.net`) falls back to `localhost`, so POSTs from it still
  get 403. The runbook (Task 17) redirects `www` to the apex at Cloudflare.
- Once the host validates, `Astro.clientAddress` becomes the *first* `X-Forwarded-For` value. Cloudflare appends to
  a client-sent header, so that value is client-controlled. Nothing uses `clientAddress` today (better-auth reads
  `cf-connecting-ip`); the config comment says not to start.

- [ ] **Step 1: Write the failing check**

```bash

# Usage (built app on :4401): bash $SCRATCH/origin-check.sh

  -H 'Host: matherly.net' -H 'X-Forwarded-Proto: https' -H 'Origin: https://matherly.net' \
  -H 'Content-Type: application/x-www-form-urlencoded' --data 'action=revoke-others' \
  http://127.0.0.1:4401/account)
[ "$code" != 403 ] || { echo "FAIL: origin check rejected a forwarded https POST ($code)"; exit 1; }
echo "PASS: $code"
```

### Task 2: Graceful shutdown on SIGTERM (C2)

**Files:**

- Create: `web/server.mjs`
- Create: `web/.dockerignore`
- Modify: `web/otel.mjs`
- Modify: `web/package.json` (`start` script)
- Scratch: `$SCRATCH/shutdown.sh` (not committed)

**Interfaces:**

- Produces: `globalThis.__otelShutdown?: () => Promise<void>` (set by `otel.mjs` when telemetry is on).

Research: the adapter installs no signal handlers and auto-starts unless `ASTRO_NODE_AUTOSTART=disabled`;
`startServer()` returns `{ server: { server: http.Server } }` (`@astrojs/node/dist/server.js:8-18`,
`standalone.js:14-30`; both undocumented, confirmed in source). OpenTelemetry's `register.js` adds a SIGTERM listener
that never exits, which removes Node's default exit (`register.js:36-48`; Node docs, signal events).

Time budget: `docker stop` and `docker compose down` wait 10 s before SIGKILL (Kubernetes 30 s), so the whole
shutdown must fit in under 10 s: drain ≤ 7 s, Sentry ≤ 1 s, OpenTelemetry ≤ 1.5 s. The OTLP exporter's own
flush timeout is 30 s, so it is capped here rather than trusted.

Signal path: the generated image runs `sh -c "exec pnpm run start"` (verified in `aspire publish` output), pnpm then
runs the `start` script in another `sh`. Ending that script with `exec node …` makes node replace the second shell;
only pnpm's forwarding remains to prove (Step 7).

- [ ] **Step 1: Write the failing check**

```bash
#!/usr/bin/env bash
# Starts the built app the way `pnpm start` does, sends SIGTERM, and asserts it exits within 9 s.
# Usage: cd web && ENTRY=… APPDB_URI=… BETTER_AUTH_SECRET=… bash $SCRATCH/shutdown.sh
set -euo pipefail
OTEL_EXPORTER_OTLP_ENDPOINT=http://127.0.0.1:4318 HOST=127.0.0.1 PORT=4401 \
  node --import ./otel.mjs ./${ENTRY:-server.mjs} >/dev/null 2>&1 &
pid=$!
for _ in $(seq 1 30); do curl -q -fs http://127.0.0.1:4401/api/auth/ok >/dev/null 2>&1 && break; sleep 1; done
kill -TERM "$pid"
for _ in $(seq 1 9); do kill -0 "$pid" 2>/dev/null || { echo "PASS: exited after SIGTERM"; exit 0; }; sleep 1; done
kill -9 "$pid"; echo "FAIL: still running 9 s after SIGTERM"; exit 1
```

The OTLP endpoint points at nothing on purpose: it proves the capped OpenTelemetry flush can't stall the exit.

- [ ] **Step 4: Create `web/server.mjs`**

```js
// Production entry: starts Astro's standalone server ourselves so SIGTERM/SIGINT drain it, flush telemetry and
// exit. @astrojs/node installs no signal handlers (dist/standalone.js); ASTRO_NODE_AUTOSTART and startServer are
// confirmed in its source (dist/server.js), not in its docs: re-check them when upgrading the adapter.
process.env.ASTRO_NODE_AUTOSTART = "disabled";
const { startServer } = await import("./dist/server/entry.mjs");
const Sentry = await import("@sentry/node");
const { server } = startServer();

// Waits for `promise` at most `ms`; a rejection counts as done (shutdown must still exit).
const within = (ms, promise) =>
  Promise.race([Promise.resolve(promise).catch(() => {}), new Promise((resolve) => setTimeout(resolve, ms))]);

let stopping = false;
async function shutdown() {
  if (stopping) return;
  stopping = true;
  // Docker sends SIGKILL 10 s after SIGTERM: drain 7 s, then flush Sentry (1 s) and OpenTelemetry (1.5 s).
  const drained = new Promise((resolve) => server.server.close(resolve));
  server.server.closeIdleConnections();
  await within(7_000, drained);
  await within(1_000, Sentry.close(1_000));
  await within(1_500, globalThis.__otelShutdown?.());
  process.exit(0);
}
process.once("SIGTERM", shutdown);
process.once("SIGINT", shutdown);
```

### Task 3: Keep password-reset tokens out of analytics and browser error reports (S1)

- [ ] **Step 2: Run it to verify it fails**

- [ ] **Step 3: Implement**

`web/src/lib/scrub-url.ts`:

```ts
// Path only: query strings and fragments can carry tokens (e.g. /reset-password?token=…).
export const stripQuery = (url: unknown): unknown => (typeof url === "string" ? url.split(/[?#]/)[0] : url);
```

- [ ] **Step 4: Use it in `Telemetry.astro`**

Umami tag gains `data-exclude-search="true" data-exclude-hash="true"`. Replace the Sentry init with:

```ts
  import { stripQuery } from "../lib/scrub-url";
  // …
  if (dsn) {
    import("@sentry/browser").then((Sentry) =>
      Sentry.init({
        dsn,
        release,
        beforeSend(event) {
          if (event.request) {
            event.request.url = stripQuery(event.request.url) as string | undefined;
            if (event.request.headers?.Referer) event.request.headers.Referer = stripQuery(event.request.headers.Referer) as string;
            delete event.request.query_string;
          }
          return event;
        },
        beforeBreadcrumb(crumb) {
          for (const key of ["url", "from", "to"]) if (crumb.data && key in crumb.data) crumb.data[key] = stripQuery(crumb.data[key]);
          return crumb;
        },
      }),
    );
  }
```

```ts
export function boundedPwned(timeoutMs = 5_000): BetterAuthPlugin {
```
